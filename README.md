# ElectroSpark Android project

A small Android WebView app containing an offline circuit-connection learning game.

## Build an APK
1. Open this folder in Android Studio (Open an existing project).
2. Let Gradle sync and install the Android SDK requested by the project if prompted.
3. Use **Build > Build Bundle(s) / APK(s) > Build APK(s)**.
4. Android Studio will show the APK location (usually `app/build/outputs/apk/debug/app-debug.apk`).

This archive contains Android source code, not a prebuilt APK. It requires Android Studio/Android SDK to compile.
