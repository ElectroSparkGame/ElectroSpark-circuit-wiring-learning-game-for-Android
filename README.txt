ElectroSpark Android App Package

INCLUDED
- index.html, manifest.webmanifest, service worker, and icons: PWA/web app package.
- android-project/: Android Studio source project wrapping the game in a native Android WebView.

BUILD APK
1. Copy/extract this folder on a computer with Android Studio.
2. Open the android-project folder in Android Studio.
3. Allow Gradle sync; install Android SDK Platform 35 if prompted.
4. Choose Build > Build Bundle(s) / APK(s) > Build APK(s).
5. Android Studio will display the generated APK path.

IMPORTANT: This ZIP contains the app source and PWA files, not a compiled APK. This environment has no Android SDK or Gradle build tools, so a signed/installed APK could not be compiled here.
